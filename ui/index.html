Ergebnisse lesen

            

              REA unterscheidet Beobachtungen,
              Ableitungen und Unbekanntes.
              „Coverage“ sagt, wie vollständig geprüft wurde. „Limitations“
              nennt Grenzen. Fehlende Angaben sind oft absichtlich als unbekannt
              markiert und keine behauptete Abwesenheit.
            

            

              Große Ausgaben werden in der Oberfläche gekürzt. Die vollständige
              Evidenz liegt als JSON unter ~/rea-artifacts/.
            

          


          

            
Wenn etwas fehlschlägt

            
    
              
  • 
                „command not found“: REA ist nicht global installiert →
                HUSKY=0 npm link in ~/rea.
              
    • 
              
  • 
                „jadx … not configured“: JADX/JDK fehlt. Der Status zeigt die
                genaue Meldung.
              
    • 
              
  • 
                „Is a directory“: Es wurde ein Ordner statt einer Datei
                übergeben.
              
    • 
              
  • 
                HTTP 406 auf /mcp: normal bei einem Browser-GET
                ohne MCP-Header.
              
    • 
            

          


          

            
Sicherheit

            

              Die Oberfläche bindet standardmäßig nur an 127.0.0.1.
              Sie hat keine Anmeldung und darf nicht ohne Schutz im Netzwerk
              freigegeben werden. Analysierte Dateien bleiben auf dem Gerät; REA
              lädt sie nicht hoch.
            

            

              Setze REA_UI_HOST nur bewusst, z. B. für einen
              vertrauenswürdigen Test. Für den normalen Gebrauch leer lassen.
            

          


          

            
MCP verbinden

            

              Der MCP-Server läuft auf Port 8765. Ein MCP-Client
              auf dem Laptop erreicht ihn nach
              adb forward tcp:8765 tcp:8765 über
              http://127.0.0.1:8765/mcp. Ein normales Browser-GET
              auf diese URL ist kein gültiger MCP-Aufruf und kann 406 liefern.
